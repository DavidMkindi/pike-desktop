From source

Run it with Python.

Pike runs on Python {{ product.python }} and installs in a couple of commands. This is the best option on Linux, or if you want to hack on it.

shell 
# clone and enter the project
git clone {{ product.github }}.git
cd pike

# create an isolated environment (optional but recommended)
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate   # macOS / Linux

# install dependencies and run
pip install -r requirements.txt
python app.py
