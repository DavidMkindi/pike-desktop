Quick start

Install the dependencies, launch the app, and connect your first provider.

shell 
pip install -r requirements.txt
python app.py

The desktop window opens automatically. On first launch, open Settings › Connection, choose a provider, paste an API key and click Test connection.

Where keys are stored. Pike writes settings to your user data folder, never into the project: %APPDATA%\Pike\settings.json (Windows), ~/Library/Application Support/Pike/ (macOS) and ~/.local/share/pike/ (Linux).

Configuration

Copy .env.example to .env or set environment variables directly. Values resolve in this order: environment, then the saved settings file, then built-in defaults.

VariableDefaultDescription
OPENAI_API_KEYemptyYour API key. Overrides the saved key.
OPENAI_BASE_URLhttps://api.openai.com/v1Any OpenAI-compatible endpoint.
OPENAI_MODELgpt-4o-miniDefault model on startup.
PIKE_MODELSbuilt-in listOverride models, e.g. llama3.2:Llama 3.2.
PIKE_REASONING_EFFORTmediumThinking level: off, low, medium, high.
PIKE_HOST127.0.0.1Bind address.
PIKE_PORT8765Port.
PIKE_DEBUGfalseEnable Flask debug mode.
PIKE_BROWSER_ONLYfalseAlways use the browser instead of the desktop window.
PIKE_TIMEOUT120Provider request timeout in seconds.
PIKE_SYSTEM_PROMPTfriendly assistantBase system prompt.
PIKE_DATA_DIRper-userWhere settings.json and history.sqlite3 live.

Using a local model (Ollama example)

.env 
OPENAI_API_KEY=ollama
OPENAI_BASE_URL=http://localhost:11434/v1
OPENAI_MODEL=llama3.2
PIKE_MODELS=llama3.2:Llama 3.2,qwen2.5:Qwen 2.5

Workspaces

A workspace is a folder Pike is allowed to work in. Open one and Pike is given a system prompt that lists the files it may touch and tells it to use its tools, which is what turns the chat into a coding agent.

  • Read - inspect files and search across the tree.
  • Write - create or update files you approve.
  • Organise - create folders, rename and delete.
  • Run - execute shell commands in an interactive terminal.

Everything is scoped to the open folder, and nothing runs without your say-so.

API reference

The backend is a small JSON + SSE API - handy if you want to embed the UI elsewhere or script Pike from another tool.

MethodEndpointPurpose
GET/The single-page frontend
GET/healthzLiveness probe
GET/api/statusConnection status, models, active model
GET/api/updateCheck for a newer release
GET / POST/api/settingsRead / update key, base URL, default model
POST/api/settings/testSend a tiny test prompt
POST/api/chatNon-streaming completion
POST/api/chat/streamStreaming completion (SSE)
GET/api/conversations?q=List / search conversations
POST/api/conversationsCreate an empty conversation
GET/api/conversations/<id>Fetch one conversation
PUT/api/conversations/<id>Replace messages
PATCH/api/conversations/<id>Rename
DELETE/api/conversations/<id>Delete one
DELETE/api/conversationsDelete all

Streaming format

The streaming endpoint emits Server-Sent Events with a small set of event types.

text/event-stream 
event: delta
data: {"text": "Hello"}

event: done
data: {"reply": "Hello world", "elapsed": 1.24}

Troubleshooting

“No API key configured”

Open Settings › Connection and save a key, or set OPENAI_API_KEY and restart.

The desktop window is blank / pywebview fails

Make sure pywebview installed correctly for your OS, or run python app.py --browser. On Linux you may need a webkit backend such as python3-gi and gir1.2-webkit2-4.1.

“Could not reach the AI provider”

Check your connection and that the Base URL matches your provider.

401 / 403 errors

The key is invalid or lacks access to the model. Try Test connection in the settings dialog.

Port already in use

Start with python app.py --port 9000.
