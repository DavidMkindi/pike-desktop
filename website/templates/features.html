Deep dive

The details that matter.

Streaming that feels instant

Replies arrive over Server-Sent Events as start, delta, done and error events. The UI renders Markdown as it streams, so code blocks and formatting settle in place while the model is still writing.

Thinking levels

For reasoning models, a Thinking picker appears next to the model selector: off, low, medium or high. The reply grows a collapsible reasoning section with an elapsed-time badge - open it when you are curious, ignore it when you are not.

A workspace, not just a chat

Open a folder and Pike receives a system prompt describing the files it may touch. It can read, write, search, create folders and run shell commands through the same tools the UI uses - all scoped to that folder.

Providers stay independent

Keys are stored per provider. Adding an OpenAI key never hides your Groq or Ollama models; models whose provider has no key yet are tagged Add key and simply prompt you to configure that provider.

Local history you can search

Every conversation is written to a SQLite file in your user data folder. Search, rename, archive or delete threads from the sidebar, and clear everything with a single action when you want a clean slate.

Light and dark, by design

A restrained grey theme with a muted blue accent, a full light theme, and a compact, responsive layout. The same tokens power the desktop app and the VS Code extension, so everything feels like one product.
